How it's deployed

Write code on a laptop; it runs on Vultr seconds later.
Laptopcommit as usual
Auto-deploya git hook copies the code to the VM on every commit
Vultr VM8 vCPU · 16 GB · New York
8 sandboxes at onceDocker, one per test run or agent
Tiger Dataevery result logged
Dedicated coresA high-performance 8 vCPU / 16 GB instance: every core goes to sandboxes, nothing else competes for them.
Native DockerOn Linux, containers run directly on the host. On a Windows or Mac laptop, Docker runs them inside an extra virtual machine.
Locked downThe firewall only allows SSH. Test sandboxes have no network; agent reruns may only reach their model API.
Same results site, remotelyThe live pipeline view runs on the VM and is opened from a laptop through an SSH tunnel.
